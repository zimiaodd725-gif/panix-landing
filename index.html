常见问题

我的资金安全吗？
安全的核心在于我们根本不接触资金。你使用自己的交易所账户，API 仅授予交易权限、无提币权限，资金始终由你掌控。
怎么收费？
核心 API 客户只对净新增利润分成，采用 High-Water Mark——先回补亏损、再谈收益。订阅研究是独立标准化产品。
最低门槛是多少？
Pilot / Starter 约 1 万美元起，用于小额真实验证；核心 API 服务从 5 万美元以上开始做分层支持。
收益有保证吗？
没有，也不会有。我们透明展示历史净值与回撤，但不承诺未来收益。数字资产交易存在较高风险。
怎么开始？
留资 → 资格筛选 → 风险说明 → 协议与授权确认 → 交易所账户与 API 权限检查 → 小额试运行 → 定期复盘。
